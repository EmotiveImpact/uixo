GETTING STARTED

One library.
Two ways to explore.

The website directory finds good sources. The asset browser helps you inspect individual components and files from indexed sources.

Start with what you need

Open All assets, search using the top bar, then filter by source, framework, format or licence evidence. Open a card to inspect its source and dependencies. Choose Get asset / install instructions to ask the registry for an authorised acquisition route.

Copying an instruction does not execute it or change your project. Review it first. Paid and account-gated files remain with their original provider.

What is in the current catalogue?

The initial source snapshot contains 67 metadata records from shadcn/ui, Lucide and Heroicons. It is not a completed live indexing run or a catalogue of thousands of downloaded files. Fonts, templates, backgrounds and other resource types still need individual-asset indexing.

Source preview not captured means no real preview is available. UIXO does not label a generic illustration as an upstream component screenshot.

Keep your favourites

Use the bookmark on a card, then open Saved. These saves stay in this browser and retain the existing 200-asset list. They are not account-synchronised or combined with website lists.

Seeing no assets?

Clear your filters first. A registry service error is not an empty result. Check registry status and one search result. They should return JSON. HTML suggests missing API routing; 503 suggests startup, database or migration trouble. A configured but unseeded database can return a genuinely empty catalogue.

Run the integrated version locally

Check out the working branch and install dependencies:

npm ci
npm run registry:deps

Run the API in one terminal:

npm run registry:dev -- --memory

Run the existing website in another:

npm run dev

Open http://127.0.0.1:5173/browse/assets. Starting only Vite does not start the registry API. Production accounts and persistent indexing need their own configuration.

For operators and AI agents

Connect through MCP. The endpoint is /api/mcp; live client verification remains a release gate. Curator review, Grok intake and indexing runs remain in the existing operator workspace and require authorisation.

Repository documentation: docs/UIXO-USER-GUIDE.md, docs/UIXO-SETUP.md, docs/STATUS.md and docs/DECISIONS.md. The full v2 agent system is not yet complete.
