## What

- **Review inbox built** at `/review`, curator-only. Loads `data/uixo-candidates.json`,
  dedupes against live listings and against itself, flags problems, and supports
  per-item and bulk approve / reject / skip with an audit trail tied to the signed-in
  curator. All 115 candidates import clean — 0 duplicates, 0 taxonomy errors.
- **Apply path:** the inbox is a browser, so Export downloads `uixo-approved.json`;
  `npm run candidates:apply -- <file> [--branch] [--dry-run]` merges it into the repo,
  renumbers `addedOrder`, and lists listings missing `public/assets/<id>.png`.
  It does not commit, push or merge. Deploy rule respected.
- **Site restructured** since the scout branched: landing page at `/`, directory at
  `/browse`, 23 prerendered pages, sitemap, feed. Live at
  https://uixo-brown.vercel.app
