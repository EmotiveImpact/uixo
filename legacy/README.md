# Legacy — pre-Vite prototype

Archived on 2026-09-10. Nothing here is built, served, or imported by the app.
Kept only as a reference for the original vanilla implementation.

- `index.html`, `app.js`, `style.css` — the original vanilla-JS site, before the
  React rewrite. Open `index.html` directly in a browser to view it.
- `assets/` (untracked) — the image and font assets the vanilla site loaded from `assets/`.
  These are untracked local copies of the files in `public/assets/`.
- `mocks/` (untracked) — design exploration screenshots and earlier drafts of the app
  (`previous-app.js`, `previous-index.html`, `previous-style.css`).

The live site is the Vite + React app at the repository root; see `../README.md`.
